# 三个工作流补全记录（2026-09-29）

## 本次交付

- **平台合规体检**：专利业务错误、异常结构及候选解析失败不再判为成功零结果；AI 输出缺必要字段时明确失败；未知视觉风险不会被低风险证据覆盖。JPEG / PNG / WEBP 使用 Sharp 读取实际尺寸，并校验真实格式。页面将专利功能明确为关键词/分类候选检索。
- **竞品图片策略**：先取图、预览、排序和确认，再提交分析。图片选择由服务端签名并绑定用户和站点；任一选图下载失败都中止本次分析，返回原图编号。不会静默删图改变顺序。上传图片也可调整顺序。缺失评分、逐图分析或制作方案时拒绝产生成功报告。
- **商品链接做图**：统一名称，保留 1688 来源范围。浏览器按用户保存链接、商品标题、事实描述和选图；进入制作前刷新即将过期的凭证，按图片 URL 保留仍有效的选择。商品图片变化导致丢失选择时要求重新确认。
- **任务与报告**：上传解析前创建任务；流式反馈阶段，支持取消、刷新后恢复和历史报告查询。取消采用数据库条件更新，迟到的模型结果不能覆盖取消状态。报告读取、取消、比较和方案导入均校验当前用户和保留期。报告保留 30 天；旧版报告提示需重新验证。
- **复检与制作**：合规报告提供整改清单和按模块的复检对比；两种报告支持 Markdown / JSON 导出。竞品方案可导入 Amazon 的补充要求，用户编辑方案、补充我方商品事实和参考图并确认后再分析，不自动复制竞品图片或执行生图。

## 实现边界

- 未新增数据库表；复用 AiOperation 的阶段、结果及过期字段。
- 任务在当前 Node 服务进程执行，刷新/离开页面不主动取消任务；不是独立的持久化作业队列。服务重启导致中断时，超过 15 分钟的任务在查询时会标记失败，需要重新提交。
- 上传原图不持久保存。历史竞品报告保留分析文字和图序，上传来源的图片预览在刷新后不可恢复；ASIN 图片预览依赖原图片地址。
- 专利功能没有自动附图相似度比较。复检按模块状态对比，不把图片变化或模型波动自动解释成整改成功。
- 商品链接草稿保存在当前浏览器，不能跨设备同步；实际来源仍为 1688。
- 取消会停止后续处理并尝试中止模型请求，不能保证上游撤销已产生的调用费用。
